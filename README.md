## About The Project

This program is coded in Java. This program will allow you to record workout volume. Then the program exports this volume to a CSV file and graphs the data. The program also produces a line of best fit, which is a polynomial of a given degree.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

Use the following links to install the necessary Java libraries and settings.json.

<li><a class="link">settings.json</a>
<li><a class="link">commons-math</a>
<li><a class="link">VectorGraphics2D</a>
<li><a class="link">xchart</a>

Then set up your project file like so:

<pre class="file-tree">
java_plotting/
│
├── .vscode/
│   └── [VS Code project settings]
│
├── lib/
│   ├── commons-math3-3.6.1.jar
│   ├── VectorGraphics2D-0.13.jar
│   └── xchart-3.8.8.jar
│
├── MathWorkoutTracker.java
├── PlotWithFunction.java
├── Test.java
│
└── workouts.csv
</pre>
